Agent Orchestrator Engine

Key design decisions Tier-based parallel execution — nodes in the same DAG tier run concurrently via asyncio + ThreadPoolExecutor. Per-tenant semaphores prevent noisy-neighbour issues. Checkpointing after every tier enables crash recovery.

Workflow DAG model

Python
@dataclass
class AgentNode:
    node_id:           str
    agent_name:        str
    depends_on:        List[str]       # node_ids that must complete first
    retry_policy:      RetryPolicy
    timeout_sec:       int  = 120
    is_human_approval: bool = False
    fallback_agent:    Optional[str] = None   # AgentV1 if AgentV2 fails


@dataclass
class Workflow:
    workflow_id: str
    tenant_id:   str
    name:        str
    version:     str
    nodes:       List[AgentNode]

    def topological_order(self) -> List[List[AgentNode]]:
        """Returns execution tiers — each tier runs fully in parallel."""
        done, tiers = set(), []
        while len(done) < len(self.nodes):
            tier = [
                n for n in self.nodes
                if n.node_id not in done
                and all(d in done for d in n.depends_on)
            ]
            if not tier:
                raise ValueError("Cycle detected in workflow DAG")
            tiers.append(tier)
            done.update(n.node_id for n in tier)
        return tiers

Orchestrator — execute loop

Python
class AgentOrchestrator:
    def __init__(self, agent_registry, tool_registry, memory_service,
                 llm_router, event_bus, checkpoint_store,
                 max_workers: int = 10):
        self._agents      = agent_registry
        self._tools       = tool_registry
        self._memory      = memory_service
        self._llm         = llm_router
        self._bus         = event_bus
        self._checkpoints = checkpoint_store
        self._executor    = ThreadPoolExecutor(max_workers=max_workers)
        # max 5 concurrent workflow executions per tenant (noisy-neighbour guard)
        self._tenant_sems: Dict[str, asyncio.Semaphore] = {}

    async def execute(
        self,
        workflow:    Workflow,
        tenant_id:   str,
        input_data:  Dict,
        resume_from: Optional[str] = None,
    ) -> ExecutionContext:

        sem = self._tenant_sems.setdefault(tenant_id, asyncio.Semaphore(5))
        async with sem:
            ctx = await self._build_context(workflow, tenant_id, input_data)
            if resume_from:
                ctx = await self._checkpoints.load(resume_from)

            for tier in workflow.topological_order():
                await self._execute_tier(ctx, tier)
                await self._checkpoints.save(ctx)     # checkpoint after every tier

            ctx.status = ExecutionStatus.COMPLETED
            await self._bus.publish("workflow.completed", ctx)
            return ctx

    async def _execute_tier(self, ctx, nodes):
        """All nodes in a tier run concurrently."""
        tasks = [
            asyncio.get_event_loop().run_in_executor(
                self._executor, self._execute_node, ctx, node
            )
            for node in nodes
        ]
        results = await asyncio.gather(*tasks, return_exceptions=True)
        for node, result in zip(nodes, results):
            if isinstance(result, Exception): raise result
            ctx.outputs[node.agent_name] = result.payload   # immutable write

    def _execute_node(self, ctx, node):
        if node.is_human_approval:
            return self._await_human_approval(ctx, node)

        agent  = self._agents.get(node.agent_name)
        policy = node.retry_policy

        for attempt in range(policy.max_retries + 1):
            try:
                result = agent.execute(ctx, self._tools, self._llm)
                self._bus.publish_sync("agent.completed", {
                    "node_id": node.node_id, "attempt": attempt
                })
                return result
            except Exception as exc:
                if attempt == policy.max_retries:
                    # try fallback agent version before giving up
                    if node.fallback_agent:
                        fallback = self._agents.get(node.fallback_agent)
                        return fallback.execute(ctx, self._tools, self._llm)
                    ctx.status = ExecutionStatus.FAILED
                    raise
                time.sleep(policy.backoff_seconds(attempt))
                ctx.status = ExecutionStatus.RETRYING

Agent Registry & Runtime

Python
class AgentRegistry:
    """
    Central store for all registered agent implementations.
    Supports versioning — orchestrator can request specific versions.
    """
    def __init__(self):
        # { agent_name: { version: Agent } }
        self._store: Dict[str, Dict[str, Agent]] = {}

    def register(self, agent: Agent, version: str = "latest") -> None:
        self._store.setdefault(agent.name, {})[version] = agent

    def get(self, name: str, version: str = "latest") -> Agent:
        try:
            return self._store[name][version]
        except KeyError:
            raise AgentNotFoundError(f"Agent '{name}' v{version} not registered")

    def find_by_capability(self, capability: str) -> List[Agent]:
        """Dynamic agent discovery — 'give me any agent that can do RAG'."""
        return [
            a for versions in self._store.values()
            for a in versions.values()
            if capability in getattr(a, "capabilities", [])
        ]

    def list_all(self) -> List[Dict]:
        return [
            {"name": name, "versions": list(versions.keys()),
             "capabilities": getattr(list(versions.values())[-1], "capabilities", [])}
            for name, versions in self._store.items()
        ]


# ── Concrete agent example ───────────────────────────────────────

class PlannerAgent(Agent):
    name         = "planner"
    version      = "v2"
    capabilities = ["planning", "decomposition"]

    def execute(self, context, tools, llm) -> AgentMessage:
        prompt = llm.get_prompt("planner", context.tenant_id)
        plan   = llm.complete(
            agent_name = self.name,
            tenant_id  = context.tenant_id,
            messages   = [
                {"role": "system", "content": prompt},
                {"role": "user",   "content": str(context.input_data)},
            ]
        )
        return AgentMessage(
            source_agent = self.name,
            execution_id = context.execution_id,
            tenant_id    = context.tenant_id,
            payload      = {"plan": plan},
        )

Tool Execution Layer

Interview gap most candidates miss Tools need a sandbox (tenant isolation), timeout enforcement, rate limiting, and a result cache to avoid redundant API calls within one execution. 
Python
class ToolRegistry:
    def __init__(self):
        self._tools: Dict[str, Tool] = {}

    def register(self, tool: Tool)   -> None: self._tools[tool.name] = tool
    def unregister(self, name: str) -> None: self._tools.pop(name, None)
    def get(self, name: str)         -> Tool: return self._tools[name]
    def list_schemas(self)           -> List[Dict]:
        return [{"name": t.name, "description": t.description,
                  "schema": t.input_schema} for t in self._tools.values()]


class ToolExecutor:
    """
    Wraps raw tool.execute() with:
      - Tenant RBAC check (is this tool allowed for this tenant?)
      - Timeout via concurrent.futures
      - Rate limiting per (tenant, tool) pair
      - Result caching within one execution
      - Sanitized output (strips dangerous keys before returning to LLM)
    """

    def __init__(self, registry, rbac, rate_limiter, cache):
        self._registry    = registry
        self._rbac        = rbac
        self._rate_limiter = rate_limiter
        self._cache       = cache

    def execute(
        self,
        tool_name:    str,
        params:       Dict,
        tenant_id:    str,
        execution_id: str,
    ) -> Dict:

        # 1. Authorization
        if not self._rbac.is_allowed(tenant_id, tool_name):
            raise PermissionError(f"Tenant {tenant_id} cannot use tool {tool_name}")

        # 2. Rate limit
        self._rate_limiter.check(tenant_id, tool_name)

        # 3. Cache hit
        cache_key = f"{execution_id}:{tool_name}:{hash(str(params))}"
        if cached := self._cache.get(cache_key):
            return cached

        # 4. Execute with timeout
        tool = self._registry.get(tool_name)
        with ThreadPoolExecutor(max_workers=1) as ex:
            future = ex.submit(tool.execute, params)
            try:
                result = future.result(timeout=30)
            except TimeoutError:
                raise ToolTimeoutError(f"{tool_name} timed out after 30s")

        # 5. Cache and return
        self._cache.set(cache_key, result, ttl=300)
        return self._sanitize(result)

    def _sanitize(self, result: Dict) -> Dict:
        # Strip keys that could carry prompt-injection payloads
        BLOCKED = {"system_prompt", "__inject__", "override_instructions"}
        return {k: v for k, v in result.items() if k not in BLOCKED}

class LLMRouter:
    """
    Primary + fallback chain. Also does cost-based routing:
      complexity=simple  → smallest model in chain
      complexity=complex → largest model (primary)
    """

    def __init__(self, primary, fallbacks, prompt_registry, vault):
        self._chain   = [primary] + fallbacks
        self._prompts = prompt_registry
        self._vault   = vault

    def complete(self, agent_name, tenant_id, messages, complexity="auto") -> str:
        chain     = self._select_chain(complexity)
        last_exc  = None
        for config in chain:
            try:
                api_key = self._vault.get(config.api_key_ref)
                return self._call(config, api_key, messages)
            except Exception as e:
                last_exc = e
        raise RuntimeError(f"All LLM providers failed. Last: {last_exc}")

    def get_prompt(self, agent_name, tenant_id) -> str:
        return self._prompts.resolve(agent_name, tenant_id)

    def _select_chain(self, complexity):
        if complexity == "simple":
            return [c for c in reversed(self._chain)]
        return self._chain

Memory Architecture

Common interview mistake Storing memory inside agents. Agents are stateless workers. Memory is an externalized service injected into ExecutionContext. 
Python
class MemoryService:
    """
    Facade over three memory backends.
    All keys are namespaced by tenant_id to ensure isolation.
    """

    def __init__(self, short_term, long_term, semantic):
        self.st = short_term   # Redis
        self.lt = long_term    # PostgreSQL
        self.sm = semantic     # Vector DB (Pinecone / Weaviate / Qdrant)

    # ── Short-term (execution scope) ────────────────────────────
    def set_short(self, tenant_id, execution_id, key, value, ttl=3600):
        self.st.set(f"{tenant_id}:{execution_id}:{key}", value, ex=ttl)

    def get_short(self, tenant_id, execution_id, key):
        return self.st.get(f"{tenant_id}:{execution_id}:{key}")

    # ── Long-term (conversation / user history) ──────────────────
    def append_long(self, tenant_id, user_id, role, content):
        self.lt.execute(
            "INSERT INTO memory (tenant_id,user_id,role,content,created_at)"
            " VALUES (%s,%s,%s,%s,NOW())",
            (tenant_id, user_id, role, content)
        )

    def get_history(self, tenant_id, user_id, limit=20) -> List[Dict]:
        return self.lt.fetchall(
            "SELECT role,content,created_at FROM memory"
            " WHERE tenant_id=%s AND user_id=%s"
            " ORDER BY created_at DESC LIMIT %s",
            (tenant_id, user_id, limit)
        )

    # ── Semantic (knowledge retrieval) ───────────────────────────
    def upsert_semantic(self, tenant_id, doc_id, text, embedding):
        self.sm.upsert(
            vectors=[{"id": f"{tenant_id}:{doc_id}",
                       "values": embedding, "metadata": {"text": text}}],
            namespace=tenant_id
        )

    def query_semantic(self, tenant_id, query_embedding, top_k=5) -> List[Dict]:
        return self.sm.query(
            vector=query_embedding, top_k=top_k,
            namespace=tenant_id,    # tenant isolation enforced here
            include_metadata=True
        ).matches

Retry, Fallback & Checkpointing

Python
@dataclass
class RetryPolicy:
    max_retries:    int   = 3
    base_delay_sec: float = 1.0
    max_delay_sec:  float = 30.0
    jitter:         bool  = True   # prevents thundering herd

    def backoff_seconds(self, attempt: int) -> float:
        delay = min(self.base_delay_sec * (2 ** attempt), self.max_delay_sec)
        if self.jitter:
            delay *= (0.5 + random.random() * 0.5)
        return delay
    
# Retry schedule (base=1.0, no jitter):
#   Attempt 0 → fail → wait 1s
#   Attempt 1 → fail → wait 2s
#   Attempt 2 → fail → wait 4s   (capped at max_delay)
#   Attempt 3 → fail → raise / try fallback agent


class CheckpointStore:
    """
    Persists ExecutionContext after every DAG tier.
    On orchestrator crash: reload from last checkpoint and resume
    from the next tier — no work is lost or duplicated.
    """

    def __init__(self, storage):   # storage = Redis or S3
        self._storage = storage

    async def save(self, ctx: ExecutionContext) -> str:
        checkpoint_id = f"ckpt:{ctx.execution_id}:{ctx.status.value}"
        await self._storage.set(
            checkpoint_id,
            json.dumps(dataclasses.asdict(ctx)),
            ex=86400  # 24-hour TTL
        )
        ctx.checkpoint_id = checkpoint_id
        return checkpoint_id

    async def load(self, checkpoint_id: str) -> ExecutionContext:
        raw = await self._storage.get(checkpoint_id)
        if not raw:
            raise CheckpointNotFoundError(checkpoint_id)
        return ExecutionContext(**json.loads(raw))

        self._producer = kafka_producer

        event = WorkflowEvent(
            event_type   = event_type,
            tenant_id    = getattr(data, "tenant_id", ""),
            execution_id = getattr(data, "execution_id", ""),
            payload      = dataclasses.asdict(data) if dataclasses.is_dataclass(data) else data,
        )
        await self._producer.send(TOPICS[event_type], json.dumps(dataclasses.asdict(event)))

    def publish_sync(self, event_type: str, data: Any):
        # Used inside sync thread-pool workers
        asyncio.run_coroutine_threadsafe(self.publish(event_type, data), self._loop)

class SecurityLayer:
    """
    Four security concerns addressed:

    1. Tool RBAC         — ToolExecutor calls rbac.is_allowed() before every execution
    2. Prompt injection  — ToolExecutor._sanitize() strips dangerous keys from tool results
    3. Secret management — LLMRouter fetches API keys from Vault at call time, never
                           stores them in config files, env vars, or DB plaintext
    4. Input validation  — Agent.validate_input() enforces JSON Schema on every message;
                           rejects oversized or malformed payloads before LLM sees them
    """

    # ── 1. Tool RBAC ─────────────────────────────────────────────────
    class ToolRBAC:
        def is_allowed(self, tenant_id: str, tool_name: str) -> bool:
            config = TenantRegistry().get(tenant_id)
            return tool_name in config.enabled_tools

    # ── 2. Prompt injection guard ─────────────────────────────────────
    # Tool results pass through _sanitize() in ToolExecutor (Section 6)
    # before being injected into LLM context.
    # Additionally, all user inputs are wrapped in a structured template
    # that separates system instructions from user content:
    #
    #   SYSTEM: {system_prompt}
    #   USER_INPUT: ###BEGIN_USER_INPUT###
    #   {user_content}
    #   ###END_USER_INPUT###
    #
    # The LLM is instructed to treat content between delimiters as data,
    # not as instructions. Injected "ignore previous instructions" payloads
    # are contained within the data section.
    

    # ── 3. Secret management ─────────────────────────────────────────
    class VaultClient:
        def get(self, path: str) -> str:
            # HashiCorp Vault or AWS Secrets Manager call
            # Secrets are fetched at call time and cached in memory ≤5 min
            # Never written to disk, logs, or error messages
            ...

    # ── 4. Input payload validation ───────────────────────────────────
    class InputGuard:
        MAX_INPUT_BYTES = 65_536   # 64 KB hard cap

        def validate(self, payload: Dict, schema: Dict) -> None:
            raw = json.dumps(payload)
            if len(raw.encode()) > self.MAX_INPUT_BYTES:
                raise ValueError("Input payload exceeds size limit")
            jsonschema.validate(payload, schema)   # raises on schema mismatch

class ObservabilityService:
    def record_span(self, span: AgentSpan):
        # 1. Push to distributed tracing backend (Jaeger / Datadog / OTLP)
        self._tracer.emit(span)
        # 2. Increment Prometheus counters / histograms
        self._metrics.record({
            "agent_latency_ms":    (span.agent_name, span.latency_ms),
            "agent_token_cost":    (span.agent_name, span.cost_usd),
            "agent_retry_total":   (span.agent_name, span.retry_count),
        })
        # 3. Write eval scores to eval store for offline analysis
        self._eval_store.write(span.trace_id, span.eval_scores)

    def record_token_usage(self, tenant_id, tokens, cost_usd):
        # Enforce monthly_token_budget from TenantConfig
        used = self._budget_store.increment(tenant_id, tokens, cost_usd)
        config = TenantRegistry().get(tenant_id)
        if used > config.monthly_token_budget:
            raise BudgetExceededError(f"Tenant {tenant_id} exceeded token budget")

Principal-Level Enhancements

These are the additions that signal production experience rather than theoretical design.

RESILIENCE
State machine execution
PENDING → RUNNING → WAITING → RETRYING → COMPLETED / FAILED. Enables long-running workflows, human gates, and precise crash recovery.
COST
Cost-based LLM routing
TaskComplexityClassifier routes simple tasks to small models and complex tasks to frontier models. Reduces cost 40–70% on typical workloads.
HUMAN-IN-LOOP
Human approval nodes
is_human_approval=True on any AgentNode pauses execution and emits an event. Workflow resumes on approval webhook, rejects trigger fallback path.
DISCOVERY
Capability-based agent selection
registry.find_by_capability("rag") dynamically selects agents at runtime. Enables self-healing workflows that find alternatives when a preferred agent is unavailable.
SECURITY
Prompt injection defense
Tool outputs sanitized before entering LLM context. User input wrapped in structured delimiters. JSON Schema validation on every agent input boundary.
QUALITY
Per-execution eval scores
Hallucination, groundedness, and relevancy scored per agent span. Stored in eval store for offline analysis, A/B prompt comparison, and regression detection.
VERSIONING
Prompt registry + A/B testing
Prompts versioned per (agent, tenant). Traffic split enables canary rollouts. Roll back a bad prompt in one API call without redeployment.
SCALE
Per-tenant concurrency control
asyncio.Semaphore per tenant caps concurrent workflows. Prevents one tenant's traffic spike from degrading latency for all others (noisy-neighbour isolation).

Closing summary

5-minute whiteboard summary The system is an Orchestrator executing tenant-configured workflow DAGs tier by tier, with parallel execution within each tier. Agents are stateless workers registered in an AgentRegistry; they communicate via typed AgentMessage contracts validated at every boundary. Tools plug in dynamically through a ToolRegistry with RBAC, timeouts, rate limiting, and result caching. Memory is externalized into three tiers: Redis (short-term), Postgres (long-term), and Vector DB (semantic). Execution is event-driven via Kafka with retries, fallbacks, checkpointing, and full observability. Multi-tenancy is enforced at config, storage, concurrency, tool, and memory layers. This scales from simple agent workflows to enterprise agentic platforms comparable to LangGraph Platform or AutoGen Studio.
